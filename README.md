#DESCRIPTION:
SkillBridge is a career intelligence platform that analyzes the gap between a user's current skills and their desired job role.

It is built using **220 real job listings from Pakistan**, collected from platforms like **Rozee.pk, LinkedIn, and Indeed**.

The system:
- Takes user career goals & current skills
- Compares them with real market data
- Identifies missing (in-demand) skills
- Provides:
  - Salary insights
  - City-wise demand
  - Personalized learning roadmap

#FEATURES:
- Analyzes 220 real Pakistan job listings
- 1156 skills tracked
- Job skill gap analysis
- Priority learning path based on market demand
- Salary range analysis
- City demand visualization
- Irrelevant skills warning

#WHAT MAKES IT UNIQUE:
Unlike most career tools that provide generic suggestions, SkillBridge is based on real job market data from Pakistan.
Every recommendation—skills, salary insights, and learning paths—is derived from actual job postings, making it more accurate and practical.
